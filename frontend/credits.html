Credits and Acknowledgements

Home > Credits

SolveBox uses fonts, images, tools and colour palettes made by other people. They are listed below with a note on what each one was used for.

SolveBox has guides for seven puzzles: the Rubik's Cube, Sudoku, crosswords, jigsaw puzzles, the Tower of Hanoi, the 15 puzzle and logic grid puzzles.

Font resources

Google Fonts

Free fonts for the web.

Thanks to Google Fonts for the fonts on the site, and to WhatTheFont for identifying fonts I liked elsewhere.

Without them, choosing fonts for this project would have taken much longer.

Image resources

Unsplash

Free photos with a permissive licence.

Unsplash and Pexels provided the puzzle photos used across the site.

They show what each puzzle looks like before you read about it.

Motivation

My School

Where this project started.

Thanks to my school, where this project began.

My teachers and classmates kept me going while I built it.

Design inspiration

Behance

Portfolios from other designers.

Behance and Dribbble were where I looked for layout ideas.

Looking through them helped settle the layout of these pages.

Development tools

VS Code

The editor used to write the site.

Thanks to Visual Studio Code and GitHub, where the site was written and is stored.

Its extensions, Live Server among them, and its Git integration made the work easier.

Color palettes

Color Hunt

Ready-made colour palettes.

Thanks to Color Hunt and Coolors for the palettes behind the colour themes.

Starting from them kept the themes consistent with each other.
